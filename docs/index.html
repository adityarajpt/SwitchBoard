Your files stay yours

No cloud detour.
No account maze.

USB transfers move between your Android device and Mac. Wi-Fi sharing uses a temporary page on your local network; it is off until you start it and can be stopped when you finish. The current Mac app does not upload your files to a SwitchBoard cloud service. Use Wi-Fi sharing only on a network you trust.

A few things people ask

Good questions, simple answers.

Do I need to install an app on my Android phone?

No. The USB method needs nothing on the phone. The Wi-Fi option opens a webpage in your phone’s browser.

Will moving photos delete them from my phone?

No. Saving files to the Mac makes copies. The app does not delete the original Android files during a transfer.

Why is my phone not appearing?

Unlock the phone, try a cable that supports data, and choose “File transfer” in the USB notification. Then scan again. See the no-jargon troubleshooting steps.

Can I send files from iPhone too?

The current build supports basic upload and download through the iPhone browser using the local Wi-Fi page. It does not browse iPhone storage or sync iOS folders directly yet.

What Mac does it work on?

The early-access app requires macOS 14 or later and Apple silicon. It is not currently notarized, so macOS may show a first-open warning. The install guide explains the safe override.
