Android phone not showing on Mac? Try these easy fixes.

Most of the time, the phone is locked, the cable only charges, or Android is waiting for you to choose what to do. Check these things before changing any advanced settings.

Try these checks in order

  1. Wake up and unlock your phone. Leave the screen on while it is connected. Some phones stop sharing files when locked.
  2. Look for a USB notification. Swipe down from the top of the Android screen. Tap the notification that mentions USB or charging. If there is a choice, tap File transfer or Transferring files, not “Charge only.”
  3. Try a different cable. A cable can charge a phone but still be unable to move files. Try the cable that came with the phone or another cable you know can transfer data.
  4. Try another Mac port. If you use an adapter or hub, connect to the Mac directly if you can.
  5. Scan once more. Open Transfer Hub, click Devices, then click Scan USB.

You do not need to turn on USB debugging. It is an advanced Android setting. The normal cable option uses File transfer mode and does not need it.

Still does not show up?

Disconnect the phone, restart it, reconnect it while unlocked, and check for the USB choice again. If the app displays a message about its USB helper, see the detailed USB troubleshooting guide. As another option, try sending files over Wi-Fi if both devices are on the same home Wi-Fi.

What are MTP and ADB?

They are names for different ways Android phones can talk to computers. You can ignore both names if you just want to copy photos. Choose Scan USB for the regular cable setup. ADB is an optional advanced method that needs extra installation and phone permission.

Check whether the phone appears in the app

When Transfer Hub finds the phone, it appears under Devices. Click the phone to open folders. Camera pictures are commonly inside DCIM → Camera. Then select photos and choose Save selected.
