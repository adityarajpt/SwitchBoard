Two Android devices

Move files between two Android phones through your Mac.

Connect both Android phones to the Mac, choose where a file should come from and where it should go, then review before sending. The Mac is the middle step—files do not jump directly between phones.

Send a few files from one phone to another

  1. Connect both Android phones to the Mac. Unlock each phone and choose File transfer if it asks.
  2. Open Transfer Hub and click Transfer.
  3. Choose the first phone as From and the second phone as To.
  4. Open the source phone's folder, select the files you want, then choose Send to the other phone.
  5. Check the destination phone's folder to make sure the files arrived.

Keep a folder up to date with a sync rule

A sync rule is a saved instruction to compare one folder on each phone when you ask it to. It is useful for keeping selected folders similar, but it does not run on its own.

  1. Open Sync in Transfer Hub.
  2. Choose the two phones and the folders you want to compare.
  3. Choose one-way (copy changes from one chosen side) or two-way (copy new files either way).
  4. Preview the list of planned changes. Resolve any conflicts you recognize.
  5. Click Apply safe changes only after reviewing the list.

Important: Sync never copies deletions, and it does not run in the background. It compares file names, sizes, and available dates—not the full contents of every file. Keep a separate backup of important files.

The QR-code Wi-Fi sharing page is for transferring selected files with a phone's browser. It cannot be chosen as one side of a phone-to-phone transfer or folder sync. Both phones need to appear as Android devices under Devices.
